# Levistro - Premium Brand Website

A modern, responsive React-based website for the Levistro brand, built with Vite for optimal performance.

## 🚀 Features

- **Modern React Architecture** - Built with React 19 and Vite for fast development and optimal performance
- **Responsive Design** - Fully responsive layout that works on all devices
- **Smooth Navigation** - Smooth scrolling between sections
- **Professional UI/UX** - Clean, modern design with beautiful animations
- **Component-Based** - Modular component structure for easy maintenance

## 📦 Pages & Sections

- **Home/Hero** - Eye-catching hero section with brand introduction
- **About** - Mission, values, and vision of Levistro
- **Products** - Showcase of product collections
- **Contact** - Contact form and company information
- **Footer** - Links and additional information

## 🛠️ Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linter
npm run lint
```

## 🏃‍♂️ Development

The development server will start at `http://localhost:5173/`

- Hot Module Replacement (HMR) is enabled for instant updates
- ESLint is configured for code quality

## 🎨 Customization

### Colors
The main brand colors are defined in the CSS files:
- Primary: `#667eea` (Purple)
- Secondary: `#764ba2` (Dark Purple)
- Text: `#2c3e50` (Dark Blue-Grey)
- Background: `#ffffff` (White)

### Content
To customize content, edit the respective component files in `src/components/`
